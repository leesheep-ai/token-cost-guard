# Token Cost Guard — public demo

A local-first dashboard for turning LLM usage CSV or JSON exports into an estimated cost report.

- [Open the demo](https://leesheep-ai.github.io/token-cost-guard/demo/)
- Usage files are parsed in the browser; nothing is uploaded.
- The complete downloadable toolkit adds the sample data, usage guide, and license.

The paid download link will be added after the storefront is configured. Pricing in the demo is editable and must be checked against the provider invoice.

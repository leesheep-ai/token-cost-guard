Before we start

How do payment and delivery work?

First we agree the exact scope, acceptance checks, delivery date and a mutually supported payment method. An inquiry is not an order. There is no automatic checkout on this site.

Can I send private logs or credentials?

Use the public inquiry only for a short project description and redacted column names. We agree a private handoff for test access. A client-owned test account and synthetic data are preferred.

What is outside the $99 pilot?

Security audits, load tests, paid API usage, browser compatibility beyond Chromium, production changes and guaranteed business or performance results require a separate agreement. The pilot reports observed behavior within the agreed scope.

Do you use AI?

Yes. Work is AI-assisted. Claims in the sample report are backed by executed tests; no client history or professional credentials are implied.
